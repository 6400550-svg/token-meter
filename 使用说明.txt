Claude Code 用量表
==================

在 Mac 屏幕右上角的菜单栏显示 Claude Code 的用量：

  · 官方额度：5 小时额度、每周额度用了百分之几，什么时候重置（每 2 分钟向 Anthropic 查一次）
      - 今日额度进度条：周额度平分到 7 天（每天从重置时刻起算 24 小时），
        哪天没用完的会累积到下一天，前几天超用了后面就少；显示今天已用 / 可用，
        以及今天还能用多少（按这周的实际用量换算成 API 价；Codex 换算成 tokens）
      - 按你现在每天的速度，到重置时会用到多少；会提前用完的话，显示大概什么时候用完
  · 本周累计：一共用了多少 token、按 API 价格折合多少钱
      - 按模型分（每个模型的单价、输入 / 输出 / 缓存明细）
      - 按思考强度分（max / xhigh / high / medium），思考 tokens 有多少
      - API 价构成（输入、输出、缓存写、缓存读各占多少）
      - 套餐使用：周额度用了几成，本周用量值套餐周费的几倍
  · 本周各窗口：桌面 App 里每个对话（Code 标签页 / Cowork）各用了多少
  · 当前 5 小时窗口、今日、近 7 天、本月的用量
  · 近 14 天每天花费、本月各项目排行
  · 第三方模型（通过代理用的 GLM、DeepSeek 等）单独列出

如果电脑上也装了 Codex（OpenAI 的编程助手，数据在 ~/.codex），会自动多出：
  · Codex 官方额度：5 小时、每周用了百分之几，精确的重置时间
    （Codex 用到 60% 以上时，菜单栏上也会显示）
  · Codex 本周：按模型、按思考强度、各线程用了多少 tokens，今日 / 近 7 天 / 本月
  · 走代理的第三方模型单独列出（不占 Codex 额度）
  · OpenAI 没公布这些模型的 API 单价，所以 Codex 只统计 tokens，不折算钱

菜单里点「查看详细报告…」会在浏览器打开一个明细页面：每日用量图、
各窗口（点开看按模型 / 思考强度 / 天 / 目录的拆分）、按模型、按思考强度、
API 价构成、每个 5 小时窗口，可以切换本周 / 今天 / 近 7 天 / 近 30 天 / 本月 / 全部。
装了 Codex 的话，页面最后还有一个 Codex 区块（每日 tokens 图、按模型、按思考强度、各线程）。

Claude 的官方额度每 2 分钟向 Anthropic 查一次（用 Claude Code 已登录的凭据，
凭据只在内存里用，不保存）；其余所有数据都只在本机读取，不上传。


安装
----
1. 双击「安装.command」。
   如果提示"无法打开，因为来自身份不明的开发者"：
   右键点「安装.command」→ 打开 → 再点「打开」。
   （或者打开「终端」，输入 bash 加一个空格，把「安装.command」拖进去，回车。）

2. 按提示回答两个问题（都可以直接回车跳过）：
   · 你的套餐：Pro / Max 5x / Max 20x
   · 每周额度的重置时间：在 Claude 桌面 App → 设置 → 用量 里能看到，
     比如"周二 15:00 重置"就填 2 和 15:00

3. 装好后看屏幕右上角，出现「5h xx% · 周 xx%」就成功了，点开看详细。

安装程序会自动检查并安装需要的东西：
  · Python 3（没有的话会弹出苹果的「命令行开发者工具」安装窗口，装完再双击一次安装）
  · SwiftBar（免费的菜单栏插件工具；有 Homebrew 会自动装，没有会打开下载页）


需要注意
--------
· Claude 官方额度要 Claude 桌面 App 或 Claude Code 在运行才查得到（用它们的登录凭据）。
  查不到时改用桌面 App 自己的额度记录；都没有时，菜单栏改为显示今日 token 数。
· "API 价"是按 Anthropic 官方 API 单价折算的，用来看用量值多少钱，
  订阅套餐并不会真的按这个收费。
· 思考强度从 2026 年 9 月起才有记录，更早的显示为"未记录"。
· "后台调用"是 Claude Code 自己发起、不写进对话记录的请求（生成标题、权限判断等），
  按 Claude Code 每次运行结束时记下的费用汇总补上；正在进行的对话要等它结束后才补。
· 只统计本机的 Claude Code（终端、桌面 App 的 Code 页和 Cowork、IDE 插件都算），
  网页版 claude.ai 的聊天不在里面。


修改设置
--------
重新双击「安装.command」即可重新选择套餐和重置时间。
设置保存在 ~/.token-meter/config.json。


卸载
----
双击「卸载.command」。
